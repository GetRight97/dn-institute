# Polymarket Potentially Informed Trading Analysis

This project investigates public Polymarket trading behavior that may be consistent with potentially informed trading.

**Analysis window:** November 1, 2025 to May 1, 2026.

The goal is not to accuse traders of insider trading. The project builds a reproducible screening pipeline, applies explainable behavioral heuristics, and ranks wallets for further investigation.

## Final Dataset Scope

The final analysis uses the **20 highest-volume closed Polymarket markets** returned under the selected date filters, subject to local validation.

A market is accepted only when:

```text
start_date is present
end_date is present
start_date < end_date
2025-11-01 <= end_date < 2026-05-01
```

The selected universe is stored in:

```text
data/raw/market_dates.csv
```

## Methodology

The predictive analysis uses **BUY trades on resolved markets that occurred before or at recorded market close**.

SELL activity is preserved in raw data but is not interpreted directionally because a SELL can represent position reduction, profit-taking, hedging, inventory management, or other portfolio behavior.

### BUY outcome hit rate

A BUY is counted as winning when the purchased outcome later resolves as the winner.

```text
490,382 winning BUY
---------------------- = 59.36%
826,167 predictive BUY
```

This is a trade-weighted baseline, not the probability that an average trader is correct.

### Outcome-leakage protection

Predictive scripts require:

```text
hours_before_close >= 0
```

Rows with negative timing are excluded before updating:

- BUY totals
- winning BUY totals
- hit rate
- BUY volume
- BUY-only profit proxy
- low-price and very-low-price signals
- wallet + market aggregates
- final ranking inputs

This prevents already-known outcomes from leaking into predictive statistics.

### Low-price winning BUYs

```text
low-price winner:      price <= 0.50
very-low-price winner: price <= 0.25
```

### Late low-price winning BUYs

```text
BUY on eventual winning outcome
price <= 0.50
0 <= hours_before_close <= 24
```

`closed_time` is a timing proxy and does not establish when relevant public information became available.

### BUY-only hold-to-resolution profit proxy

For a winning BUY:

```text
profit_proxy = size * (1 - price)
```

For a losing BUY:

```text
profit_proxy = -size * price
```

This is **not realized P&L**.

### Wallet + market aggregation

Signals are first aggregated at:

```text
wallet + market
```

and then summarized across markets.

## Candidate Ranking

Each wallet receives a 0–100 investigation-priority score.

| Component | Maximum |
|---|---:|
| Very-low-price cross-market evidence | 25 |
| Late low-price cross-market evidence | 20 |
| BUY hit-rate edge vs global baseline | 20 |
| Profitable-market ratio | 15 |
| BUY-only hold-to-resolution profit proxy | 10 |
| Cross-market breadth | 5 |
| BUY volume | 5 |
| **Total** | **100** |

A reliability factor based on BUY count and market count reduces the influence of small samples.

```text
>= 75    VERY HIGH
>= 60    HIGH
>= 45    ELEVATED
>= 30    MODERATE
< 30     LOW
```

These labels indicate heuristic signal strength only.

## Limitations

- only 20 selected high-volume closed markets are analyzed;
- only 18 selected markets contain in-window trades;
- public data cannot reveal a trader's actual information set;
- `closed_time` is not necessarily the first public-information timestamp;
- BUY-only profit proxy is not realized P&L;
- SELL trades are not directionally modeled;
- related markets can reflect the same underlying event;
- wallets do not necessarily correspond to individual people;
- automated strategies can create repeated patterns;
- the reliability adjustment is heuristic rather than a formal significance test;
- market prices are only approximate probability signals.

## Interpretation

A high score means the wallet's public trading behavior is unusually consistent with the selected screening heuristics.

It does **not** mean the wallet has been proven to possess material non-public information or to have engaged in unlawful conduct.
